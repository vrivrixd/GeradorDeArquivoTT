# TeamTalk File Generator
A program that generates TeamTalk server files (.tt), made with [AutoHotkey](https://autohotkey.com) v1.
Available in English and Portuguese.

[Versão em português abaixo.](#gerador-de-arquivo-tt)

## Download
Get the latest version from the [Releases](https://github.com/vrivrixd/TeamTalk-File-Generator/releases) page:
- `TeamTalk-File-Generator-en.exe`: English
- `TeamTalk-File-Generator-pt-BR.exe`: Portuguese

## How to use
When you run the program, fill in the server details, the account to use, a nickname (optional) and the channel the user should join (optional).
Then choose Generate file, and pick the folder and the name for the file.

## Running from source
You need [AutoHotkey](https://autohotkey.com) v1.1, both to run and to compile.
Run `english.ahk` for the English version or `portugues.ahk` for the Portuguese version. Both use the shared code in `teamtalk_file_generator.ahk`, which should not be run on its own.

## Compiling
Press the Applications key or right-click `english.ahk` or `portugues.ahk`, and choose Compile script, or if you prefer, Compile script (GUI).
The GUI option lets you customize the options for compressing the .exe file and the architecture.

## Translating
To add a language, copy `english.ahk` to a new file, translate the texts between quotes, and save it as UTF-8 with BOM.

# Gerador de Arquivo TT
Um programa para gerar arquivos de servidores do TeamTalk (.tt), feito em [AutoHotkey](https://autohotkey.com) v1.
Disponível em inglês e português.

## Download
Baixe a versão mais recente na página de [Releases](https://github.com/vrivrixd/TeamTalk-File-Generator/releases):
- `TeamTalk-File-Generator-pt-BR.exe`: português
- `TeamTalk-File-Generator-en.exe`: inglês

## Forma de uso
Ao executar o programa, preencha os dados do servidor, a conta a ser usada, o apelido (opcional) e o canal onde o usuário deve entrar (opcional).
Em seguida, escolha Gerar arquivo, e selecione a pasta e o nome do arquivo.

## Executando da fonte
Você precisa do [AutoHotkey](https://autohotkey.com) v1.1, tanto para executar quanto para compilar.
Execute `portugues.ahk` para a versão em português ou `english.ahk` para a versão em inglês. Os dois usam o código compartilhado em `teamtalk_file_generator.ahk`, que não deve ser executado sozinho.

## Compilação
Dê aplicações ou clique com o botão direito em `portugues.ahk` ou `english.ahk`, e escolha Compile script, ou se preferir, Compile script (GUI).
A opção GUI te permite personalizar as opções para a compactação do arquivo .exe e arquitetura.
